🚀 AP News 웹앱 GitHub 업로드 및 배포 가이드

본 문서는 작성하신 Flask 기반 AP News 영어 학습 플랫폼(app_v2.py) 소스 코드를 GitHub에 안전하게 업로드하고, 전 세계 어디서든 접속할 수 있도록 웹 서버에 무료로 배포하는 방법을 안내합니다.

Phase 1 배포를 위한 사전 준비

웹 서버가 파이썬 환경을 구성할 수 있도록 필수 파일 두 가지(의존성 파일, 무시 파일)를 만듭니다.

1. requirements.txt 생성

터미널(명령 프롬프트 또는 PowerShell)에서 프로젝트 폴더로 이동한 뒤, 아래 패키지 목록을 담은 requirements.txt 파일을 생성하세요.

Flask==3.0.0
flask-cors==4.0.0
beautifulsoup4==4.12.2
requests==2.31.0
curl_cffi==0.5.9
gTTS==2.4.0
googletrans==4.0.0-rc1
feedparser==6.0.10
eng_to_ipa==0.0.2
nltk==3.8.1

2. .gitignore 파일 생성

불필요한 캐시 파일이나 파이썬 가상환경 파일이 GitHub에 올라가지 않도록 프로젝트 최상단 폴더에 .gitignore 파일을 만듭니다.

# 파이썬 캐시
__pycache__/
*.pyc

# 가상 환경
venv/
env/
.env

# NLTK 데이터 등
nltk_data/

Phase 2 GitHub에 소스 코드 올리기

1. GitHub 저장소(Repository) 생성

  1. GitHub에 로그인합니다.
  2. 우측 상단의 + 버튼을 누르고 New repository를 클릭합니다.
  3. 저장소 이름(예: apnews-english-lab)을 입력하고 Public으로 설정한 뒤 Create repository를 클릭합니다.

2. 로컬에서 Git으로 업로드

터미널을 열고 프로젝트 폴더(e:\01_git\HK_DX_Model\28_APNews)에서 다음 명령어를 순서대로 입력합니다.

# Git 초기화
git init

# 모든 파일 추가
git add .

# 첫 커밋 작성
git commit -m "🚀 Initial commit: AP News English Lab v2"

# 브랜치명 main으로 변경
git branch -M main

# GitHub 원격 저장소 연결 (본인의 GitHub 주소로 변경하세요)
git remote add origin https://github.com/[본인아이디]/[저장소이름].git

# 푸시하여 업로드 완료!
git push -u origin main

Phase 3 웹으로 구동하기 (Render.com 추천)

우리가 사용하는 curl_cffi 모듈(Cloudflare 우회 엔진)은 C 모듈을 포함하고 있어 일부 무료 호스팅(PythonAnywhere 등)에서 작동하지 않을 수 있습니다. 따라서 컨테이너 기반의 Render.com 웹 서비스를 무료로 사용하는 것을 강력히 추천합니다.

⚠️ 중요: 시작 명령 파일(Procfile) 생성 혹은 app.py 이름 변경 Render 서버는 기본적으로 app.py를 찾습니다. app_v2.py를 실행하게 하려면 Gunicorn이 필요합니다.
requirements.txt 맨 끝에 gunicorn을 추가하고 배포하세요.

1. Render 가입 및 Web Service 생성

  1. Render.com에 접속하여 GitHub 계정으로 로그인합니다.
  2. Dashboard에서 New + 버튼을 클릭하고 Web Service를 선택합니다.
  3. Build and deploy from a Git repository를 선택하고, 앞서 만든 GitHub 저장소를 연결(Connect)합니다.

2. 서비스 설정 및 배포 (Deploy)

연결 후 나오는 설정 화면에서 아래와 같이 설정하세요.

  • Name: apnews-english-lab (자유롭게 입력)
  • Language: Python 3
  • Branch: main
  • Build Command: 
    pip install -r requirements.txt
  • Start Command: 
    gunicorn app_v2:app
  • Instance Type: Free (무료 플랜 선택)

3. NLTK 사전 데이터 다운로드 (선택사항)

서버가 처음 시작할 때 app_v2.py 안에 작성해 둔 코드가 자동으로 `wordnet` 데이터를 다운로드하므로 특별한 설정이 필요하지 않습니다. (자동화 완료됨)

4. 배포 완료 확인

Create Web Service 버튼을 누르면 서버가 셋팅(Build)을 시작합니다. 로그(Logs) 탭을 보면서 Build successful이 뜨면, 좌측 상단에 제공된 URL (예: https://apnews-english-lab.onrender.com)을 클릭하여 전 세계 어디서든 접속하세요!
