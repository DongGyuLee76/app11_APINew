## 🎯 원인 분석

### **1. 주요 원인: Android STORAGE 권한 문제** 🔴

**`main_fixed.py` 40-42번 줄에서 문제 발견:**

```python
# ❌ 문제 코드
perms = [
    Permission.INTERNET,
    Permission.WRITE_EXTERNAL_STORAGE,    # ← 문제!
    Permission.READ_EXTERNAL_STORAGE,     # ← 문제!
    Permission.ACCESS_NETWORK_STATE
]
```

#### 왜 문제인가?

1. **buildozer.spec과 불일치**
   - buildozer.spec: `android.permissions = INTERNET,ACCESS_NETWORK_STATE`
   - Python 코드: STORAGE 권한도 요청
   
2. **Android 10+ (API 29+) 호환성 문제**
   - `WRITE_EXTERNAL_STORAGE`와 `READ_EXTERNAL_STORAGE`는 **deprecated**
   - Android 10 이상에서 요청 시 **앱 충돌** 발생
   - 현재 빌드: `android.api = 31` (Android 12) → 충돌 유발

3. **권한 요청 실패 = 앱 크래시**
   - 앱 시작 시 `on_start()`에서 즉시 권한 요청
   - 권한 요청 실패 → 예외 발생 → 앱 종료

### **2. 부차적 원인**

- **에러 핸들링 부족**: 권한 요청 실패 시 예외 처리 미흡
- **캐시 경로 문제**: `/sdcard` 경로 접근 시 권한 오류 가능
- **초기화 순서**: NLTK, 권한 요청 순서 문제

## ✅ 해결 완료

### **주요 수정사항**

#### **1. STORAGE 권한 제거**

```python
# ✅ 수정된 코드
perms = [
    Permission.INTERNET,
    Permission.ACCESS_NETWORK_STATE  # STORAGE 권한 제거!
]
```

#### **2. 권한 체크 강화**

```python
# 권한 체크 시 예외 처리 추가
for perm in perms:
    try:
        if not check_permission(perm):
            needed_perms.append(perm)
    except:
        needed_perms.append(perm)
```

#### **3. on_start() 메서드 안전성 강화**

```python
def on_start(self):
    try:
        request_android_permissions()
    except Exception as e:
        print(f"⚠️ 권한 요청 중 오류 (계속 진행): {e}")
    
    try:
        threading.Thread(target=self._init_nltk, daemon=True).start()
    except Exception as e:
        print(f"⚠️ NLTK 초기화 실패 (무시): {e}")
```

#### **4. 캐시/TTS 파일 경로 개선**

```python
# ❌ 문제였던 코드
temp_dir = '/sdcard'  # STORAGE 권한 필요!

# ✅ 수정된 코드
try:
    from android.storage import app_storage_path
    temp_dir = app_storage_path()  # 앱 전용 저장소
except:
    temp_dir = '.'  # 현재 디렉토리 (권한 불필요)
```

## 💡 핵심 포인트

### **Android 10+ 앱 개발 시 주의사항**

1. **STORAGE 권한 사용 금지**
   ```python
   # ❌ 절대 사용하지 말 것
   Permission.WRITE_EXTERNAL_STORAGE
   Permission.READ_EXTERNAL_STORAGE
   ```

2. **앱 전용 저장소 사용**
   ```python
   # ✅ 권장 (권한 불필요)
   from android.storage import app_storage_path
   cache_dir = app_storage_path()
   ```

3. **Scoped Storage 사용**
   - Android 10+ (API 29+)는 Scoped Storage 필수
   - `/sdcard` 직접 접근 금지
   - 앱 전용 디렉토리만 사용

4. **권한과 buildozer.spec 일치**
   ```ini
   # buildozer.spec
   android.permissions = INTERNET,ACCESS_NETWORK_STATE
   ```
   ```python
   # Python 코드도 동일하게
   perms = [Permission.INTERNET, Permission.ACCESS_NETWORK_STATE]
   ```
