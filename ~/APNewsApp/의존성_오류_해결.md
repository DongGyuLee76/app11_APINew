# 🔧 의존성 모듈 오류 해결 가이드

## 📋 문제 증상

앱 실행 시 다음 에러 메시지 표시:
```
번역 오류: No module named 'typing_extensions'
TTS 오류, HTTP 오류: No module named 'httpcore'
```

---

## 🎯 원인 분석

### **근본 원인: googletrans 의존성 누락**

`googletrans==4.0.0rc1`은 다음 모듈들을 필요로 하지만, buildozer requirements에 명시되지 않음:

1. **typing-extensions**
   - Python typing 시스템 확장
   - googletrans의 내부 타입 시스템에 필수

2. **httpcore**
   - httpx의 핵심 엔진
   - HTTP/1.1 및 HTTP/2 지원

3. **httpx**
   - googletrans가 사용하는 현대적인 HTTP 클라이언트
   - requests 대신 사용

4. **h11**
   - HTTP/1.1 프로토콜 구현
   - httpcore가 사용

5. **anyio, sniffio**
   - 비동기 I/O 추상화 라이브러리
   - httpx/httpcore가 사용

### **추가 의존성**

**gtts 의존성:**
- click: 명령줄 인터페이스 도구

**기본 HTTP 의존성:**
- urllib3: HTTP 연결 풀링
- idna: 국제화 도메인 이름
- certifi: SSL 인증서
- charset-normalizer: 문자 인코딩 감지
