## 🔍 원인 분석

### **문제 1: 번역 결과 인코딩 오류**

**원인:**
- deep-translator가 제대로 작동 안 함
- 또는 UTF-8 인코딩 문제

**해결:**
- deep-translator → googletrans → 간단한 사전 (3단계 fallback)
- UTF-8 명시적 처리

### **문제 2: 한글 폰트 없음**

**원인:**
- Kivy 기본 폰트 = Roboto (한글 미지원)
- 한글 = □□ (깨짐)

**해결:**
- 안드로이드 시스템 폰트 등록: `/system/fonts/DroidSansFallback.ttf`
- 모든 Label에 `font_name='Korean'` 적용

---

## ✅ 해결 방법

### **1. 한글 폰트 등록**

```python
from kivy.core.text import LabelBase

def register_korean_font(self):
    """한글 폰트 등록"""
    font_paths = [
        '/system/fonts/DroidSansFallback.ttf',  # ← 안드로이드 기본
        '/system/fonts/NanumGothic.ttf',
    ]
    
    for font_path in font_paths:
        if os.path.exists(font_path):
            LabelBase.register(
                name='Korean',
                fn_regular=font_path
            )
            print(f"✅ 한글 폰트 등록: {font_path}")
            break
```

### **3. 번역 3단계 Fallback**

```python
def translate_text(self, text):
    """텍스트 번역 (3단계 fallback)"""
    
    # 1단계: deep-translator
    try:
        from deep_translator import GoogleTranslator
        translator = GoogleTranslator(source='en', target='ko')
        result = translator.translate(text)
        if result:
            return result  # ✅ 성공
    except:
        pass
    
    # 2단계: googletrans
    try:
        from googletrans import Translator
        translator = Translator()
        result = translator.translate(text, src='en', dest='ko')
        if result and result.text:
            return result.text  # ✅ 성공
    except:
        pass
    
    # 3단계: 간단한 사전
    return self._simple_translate(text)  # ✅ 최소한 작동
```

### **4. 간단한 사전 번역**

```python
def _simple_translate(self, text):
    """간단한 단어 사전"""
    translations = {
        'Trump': '트럼프',
        'Putin': '푸틴',
        'Ukraine': '우크라이나',
        'war': '전쟁',
        'says': '말하다',
        'will': '것이다',
        'meet': '만나다',
        # ... 더 많은 단어
    }
    
    result = text
    for en, ko in translations.items():
        result = result.replace(en, ko)
    
    return result
```

## 💡 핵심 개선

### **1. 한글 폰트** 
- **DroidSansFallback.ttf**: 모든 안드로이드 기기 기본 탑재
- **한글, 한자, 일본어 모두 지원**
- **APK 크기 증가 없음** (시스템 폰트 사용)

### **2. 3단계 번역 Fallback**

```
1차: deep-translator (가장 안정적)
  ↓ 실패
2차: googletrans (많이 사용됨)
  ↓ 실패
3차: 간단한 사전 (항상 작동)
```

**결과:** 어떤 경우에도 **번역이 작동함** ✅

## ⚠️ 주의사항

### **googletrans 설치 실패 시**

googletrans가 안드로이드에서 문제를 일으키면:

**Option 1: requirements에서 제거**
```txt
# googletrans==4.0.0rc1  ← 주석 처리
```

**Option 2: 코드는 그대로 유지**
- googletrans import 실패 → deep-translator 시도
- 둘 다 실패 → 간단한 사전 사용
- **앱은 정상 작동** ✅
