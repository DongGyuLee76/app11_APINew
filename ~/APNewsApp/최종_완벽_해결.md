# 🎯 한글 깨짐 + 의존성 오류 최종 해결

## 📋 문제 상황 (이미지 분석)

1. **한글 깨짐**: "번 1" (기사 1), "번역 오류" 등
2. **여전히 동일한 에러**:
   - `No module named 'typing_extensions'`
   - `module 'httpcore' has no attr`

---

## 🔍 근본 원인 분석

### **문제 1: googletrans는 안드로이드에서 작동 불가** 🔴

**핵심 문제:**
- `googletrans`와 그 의존성들(`typing-extensions`, `httpx`, `httpcore` 등)은 **python-for-android에서 공식 지원하지 않음**
- buildozer.spec에 추가해도 **제대로 빌드되지 않음**
- 설치되어도 런타임에서 **import 오류 발생**

**증거:**
```
번역 오류: No module named 'typing_extensions'
TTS 오류, HTTP 오류: module 'httpcore' has no attr
```

### **문제 2: Kivy 기본 폰트는 한글 미지원** 🟠

**핵심 문제:**
- Kivy는 기본적으로 **Roboto 폰트** 사용
- Roboto는 **라틴 문자만 지원**, 한글 없음
- 한글이 깨져서 "번 1" (□□ 1) 처럼 표시됨

**필요한 해결:**
- 한글을 지원하는 폰트 등록 필요
- 안드로이드 시스템 폰트 활용 또는 폰트 파일 포함

---

## ✅ 최종 해결 방법

### **전략: googletrans 완전 제거 + 한글 폰트 추가**

#### **왜 googletrans를 제거하나요?**

1. python-for-android 비호환
2. 의존성 지옥 (typing-extensions, httpx, httpcore, h11, anyio, sniffio...)
3. 빌드 시간 증가
4. 런타임 오류 빈번
5. **앱 안정성 최우선**

#### **대안:**
- 번역 기능은 **나중에 웹 API로 구현** (추후 업데이트)
- 현재는 **TTS만 유지**하여 안정성 확보

# 안드로이드 시스템 폰트 사용
def get_font_path(self):
    if platform == 'android':
        system_fonts = [
            '/system/fonts/DroidSansFallback.ttf',  # 안드로이드 기본 한글 폰트
            '/system/fonts/NanumGothic.ttf',

if font_path:

        name='NanumGothic',

    text="기사 1",

## 💡 왜 안드로이드 시스템 폰트를 사용하나요?

### **장점:**
1. **별도 파일 불필요**: APK 크기 증가 없음
2. **모든 안드로이드 기기 호환**: DroidSansFallback은 기본 탑재
3. **한글 완벽 지원**: CJK (한중일) 문자 모두 지원
4. **빠른 로딩**: 이미 시스템 메모리에 있음

### **DroidSansFallback.ttf란?**
- 안드로이드 기본 폰트
- **Fallback** = 기본 폰트에 없는 문자 처리
- **한글, 한자, 일본어 모두 지원**
- 경로: `/system/fonts/DroidSansFallback.ttf`

### **방법 1: 웹 API 사용 (권장)**

```python
import requests

def translate_to_korean(self, text):
    """Papago API 또는 Google Cloud Translation API"""
    api_url = "https://openapi.naver.com/v1/papago/n2mt"
    headers = {
        "X-Naver-Client-Id": "YOUR_CLIENT_ID",
        "X-Naver-Client-Secret": "YOUR_CLIENT_SECRET"
    }
    data = {
        "source": "en",
        "target": "ko",
        "text": text
    }
    response = requests.post(api_url, headers=headers, data=data)
    result = response.json()
    return result['message']['result']['translatedText']
```
