## 🎯 가능한 원인 (우선순위 순)

### **1. googletrans 라이브러리 문제** 🔴 (가장 가능성 높음)

**문제 코드 (main_fixed.py 298번 줄):**
```python
# build() 메서드에서
try:
    self.translator = Translator()  # ← 안드로이드에서 충돌!
except:
    pass
```

**왜 문제인가?**
- `googletrans`는 Google Translate API를 비공식적으로 사용
- **SSL/TLS 인증서 문제**로 안드로이드에서 충돌
- `httpx`, `httpcore` 의존성이 안드로이드와 비호환
- 네트워크 초기화 시점에 충돌 가능

**증거:**
- requirements에 `googletrans==4.0.0rc1` 포함
- build() 메서드에서 즉시 Translator() 생성
- 안드로이드에서 초기화 실패 → 앱 충돌

- import 시점에 충돌 가능

### **3. BeautifulSoup HTML 파서 문제** 🟡


### **4. NLTK 초기화 문제** 🟡

**문제 코드 (62-73, 278-289번 줄):**
```python
import nltk  # 전역 import

def init_nltk_safe():
    try:
        import nltk
        nltk.data.find('corpora/wordnet.zip')
    except:
        nltk.download('wordnet', quiet=True)  # 안드로이드에서 실패 가능
```

**왜 문제인가?**
- NLTK는 크고 복잡한 라이브러리
- 안드로이드에서 데이터 경로 찾기 실패 가능
- wordnet 다운로드 시 네트워크/파일 시스템 오류

**하지만:**
- 백그라운드 스레드에서 실행
- on_start()에서 try-except로 감싸져 있음 → 중간 우선순위

### **3. Translator Lazy 초기화**

```python
def _get_translator(self):
    """필요할 때만 Translator 생성"""
    if self.translator is None:
        try:
            from googletrans import Translator
            self.translator = Translator()
        except Exception as e:
            print(f"❌ Translator 초기화 실패: {e}")
            self.translator = False  # 재시도 방지
    return self.translator if self.translator else None
```
